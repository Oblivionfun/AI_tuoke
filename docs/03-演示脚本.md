# 给冠维老板的演示脚本（约 15 分钟）

目标：让老板看到三件事——**系统找到的客户是真的、每条信息都有出处、业务员每天只需要花半小时**。

## 演示前准备（前一天）

1. `workbench demo seed`：载入已经做好的 18 张真实客户卡（阿联酋 8、南非 6、沙特 4，含 3 封演示草稿）。这些卡片由研究子代理按同一份提示词契约联网调研，再由另一个审查子代理点开来源复核，运行页会标明"演示数据"。
2. 有 `OPENAI_API_KEY` 时，执行 `workbench doctor --live` 确认模型和联网搜索可用，现场再跑一轮"阿联酋 × 自钻螺钉"展示实时步骤；没有 key 就只展示预置卡片。
3. 对照组已经做好：`eval/reports/baseline-compare.md`（见下方"现成的对比结果"）。如果想用 ChatGPT 网页版的真实回答，整理成同样格式的 YAML 后执行 `workbench eval baseline 文件名`。
4. 工厂至少确认 3-5 个首推 SKU，否则文案只能写产品名，说服力会弱。
5. 网络兜底：现场跑不动时，直接展示预置卡片和运行记录。

## 现成的对比结果（2026-10-10）

让一个大模型不联网、凭记忆列出 40 家阿联酋 / 南非 / 沙特紧固件批发商和邮箱，再用程序逐条检查：

| | 直接问聊天机器人 | 工作台卡片 |
| --- | --- | --- |
| 公司数 | 40 | 18 |
| 域名根本不存在 | 27（68%） | 0 |
| 官网能打开 | 9（22%），另有 2 家存在但拒绝自动访问 | 18，调研时逐家打开 |
| 邮箱能在官网上找到 | 1（2%） | 每个邮箱都附出处页面，审查逐字核对过 |
| 判断是不是买家 | 否：前三家是伍尔特、喜利得、慧鱼，都是品牌商，不会向永年工厂采购 | 是：同行已剔除 |

可以讲的三个细节：

- **审查 agent 抓出伪装成经销商的同行**：南非 Tru-Fix 官网正文写 "Distributor"，但网页源码描述写着 "the leading manufacturer"，锚栓页写 "Trufix manufactures"。调研时漏了，审查时点开来源发现，退回返工。
- **两个子代理独立发现同一个集团**：阿联酋的 Fastener World 和沙特的 Al-Khamisain 都属于迪拜的 Asia Bolts 制造集团，两边各自判为同行。
- **南非合规**：六角类产品在反倾销调查中，卡片自动改推铆钉、自钻螺钉、垫圈、锚栓；首封只征求同意，而且邮件和电话二选一，只联系一次。

## 演示流程

| 时间 | 页面 | 讲什么 |
| --- | --- | --- |
| 0-2 分 | 产品库 | "这是冠维 84 张产品卡，从样册导入。工厂确认了这几个首推 SKU，系统写信只用这些规格，不会乱报。" |
| 2-6 分 | 运行 | 现场点"寻客：阿联酋 × 自钻螺丝"。屏幕上实时出现"搜索：…""打开：…"。"它像业务员一样上网查，但同时查 5 家。" |
| 6-9 分 | 客户档案 | 打开一张卡：公司是谁、卖什么、和我们哪个 SKU 对得上、联系入口在哪。"每一条都能点开出处；查不到的写'未找到'，不瞎编。"再打开审查意见："另一个 AI 专门挑毛病，点开来源核对过。" |
| 9-11 分 | 今日审核 | 点"接受"，几秒后出现中英对照的首封邮件。"业务员复制到公司邮箱里自己发，系统不代发，不会把域名发黑。" |
| 11-13 分 | 对比 | 打开对比表："直接问聊天机器人的 40 家里，27 家的网址根本不存在，邮箱只有 1 个能在官网上找到，前三家还是伍尔特、喜利得这种品牌商。我们的卡片每家都核对过。" |
| 13-15 分 | 南非卡片 + 跟进记录 | "南非六角类产品在反倾销调查，系统自动改推垫圈和锚栓，首封只征求同意。"最后看跟进记录："谁回了、要了什么报价，都记在这里。" |

## 老板可能会问

- **一个月能出多少询盘？** 试点 30 天，每天 10 封，一共约 200-300 封。冷邮件回复率按行业经验 1-5% 估，大约 2-15 个回复。这是估算，以试点数据为准。
- **花多少钱？** 每张卡的模型和搜索费用会记录在运行页，试点第一周就有实测数字。服务器约每月几十美元。
- **和买数据、发开发信软件有什么区别？** 那些是"先发再说"，我们是"先查实、再出手"：数量少，但每封都发给对得上的人，域名不会被封。
- **能不能自动发？** 第一版故意不做。先用人工发送跑出回复率，合规确认后再考虑。
