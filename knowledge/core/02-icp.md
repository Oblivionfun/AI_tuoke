# 目标客户画像

## 要找的（买家）

按优先级：

1. **紧固件进口商 / 批发商 / 库存商**：官网有紧固件产品目录，自述 importer、stockist、wholesaler、distributor、trading。
2. **五金建材批发、工业品（MRO）供应商**：紧固件是主要品类之一。
3. **钢结构、幕墙、光伏支架、屋面系统的承包商或配套商**：有采购部门、公开招供应商。
4. **自有品牌商**：在当地卖自有品牌紧固件，但自己不生产。

## 不要的（不是买家）

- **紧固件制造商（同行）**：官网写自有工厂、生产线、冷镦机。"制造 + 贸易"兼营的可以保留，在风险里标注。
- **零售终端**：只有门店、只卖给个人消费者的五金店、电商店铺。
- **平台和目录站**：阿里巴巴、黄页、B2B 名录本身不是公司。
- **中国工厂或贸易公司的海外办事处**：是竞争对手。
- **紧固件制造集团的销售分公司或关联贸易公司**：自己的官网只写"库存、贸易"，但集团官网或新闻显示它属于以制造为主的集团（例如同一集团下有冷镦工厂）。它会优先卖集团自产的货，按同行处理。
- **拒绝联系名单和已处理名单里的公司**（输入里会给）。
- 目标国家说明里点名排除的公司或协会成员。
